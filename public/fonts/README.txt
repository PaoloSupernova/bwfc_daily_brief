PLACE BRAND FONT FILES HERE (FOR ON-SCREEN USE)

This folder holds the .woff2 versions of the BWFC brand fonts. They are
downloaded by the browser when anyone loads the app.

REQUIRED FILES (filenames must match exactly):

  Nippo-Regular.woff2
  Nippo-Medium.woff2
  Nippo-Bold.woff2
  Satoshi-Regular.woff2
  Satoshi-Medium.woff2
  Satoshi-Bold.woff2
  BuiltTitling-Regular.woff2  (optional - falls back to Archivo Black)

WHERE TO GET THEM:

  Nippo:    https://www.fontshare.com/fonts/nippo
  Satoshi:  https://www.fontshare.com/fonts/satoshi

Both are free to download with a Fontshare account.

The downloads come as .otf files. To convert to .woff2:

  1. Visit https://transfonter.org
  2. Upload all the .otf files at once
  3. Tick the WOFF2 format option only
  4. Click Convert
  5. Download the zip
  6. Drop the resulting .woff2 files into this folder

If the files are missing, the app gracefully falls back to Google Fonts
alternatives (Inter for Satoshi, Archivo Narrow for Nippo, Archivo Black
for Built Titling). Nothing breaks if a font is missing.

This file can be deleted once the fonts are in place.
